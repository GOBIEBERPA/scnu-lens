# SCNU Lens — 순천대 AI 통합 알리미

> 흩어진 순천대 공지 100여 곳과 공모전·자격증 일정을 한곳에 모으고, **나에게 해당되는 것만 골라 마감 전에 알려주는** 모바일 웹앱

**🔗 바로 써 보기: https://scnuaram.vercel.app**

1. 접속하면 뜨는 **30초 설정**에서 학과(예: `컴공` 입력 → 컴퓨터공학전공)와 관심사를 고릅니다.
2. **나에게** 탭에서 나에게 맞는 공지와 *왜 추천했는지*를 봅니다.
3. 공지를 누르면 대상·기간·신청방법이 정리된 카드가 열립니다. 알림을 켜면 마감 7·3·1일 전에 휴대폰으로 알려줍니다.

---

## 🙋 문제

- 순천대 공지는 학사·장학 본부 게시판과 **학과·부속기관 게시판 100곳 넘게** 흩어져 있습니다. 공모전·자격증 일정은 또 다른 사이트에 있습니다.
- 같은 공지가 여러 게시판에 중복으로 올라오고, 마감일·신청 방법은 본문과 첨부파일(HWP·PDF) 속에 묻혀 있습니다.
- 그래서 나에게 해당되는 기회를 **모르고 지나치거나 마감을 놓칩니다.**

## 💡 해결 — 핵심 기능

| 기능 | 설명 |
|---|---|
| **통합 수집** | 순천대 게시판 **109곳** + 학사·장학 공지를 **매시간** 자동 수집 (학교 사이트 외 주소는 코드에서 차단) |
| **공모전·자격증·창업** | 공공데이터포털 API 3종 — 큐넷 국가자격 시험일정, 데이터 자격검정(ADsP·SQLD), K-Startup 창업 공고(대학생 대상·전국/전남광주만) |
| **AI 분류** | 유료 API 없이 서버 안의 다국어 임베딩 모델(MiniLM, ONNX)로 학사·장학·취업·경진대회·행사·자격증 분류 |
| **정리 카드** | 본문·첨부(HWP/PDF)에서 대상·기간·신청방법·문의·장소를 뽑아 표로 정리 |
| **마감 D-day** | 마감일 추출, `D-3 마감`·`오늘 마감`·`마감됨` 표시, 월 달력에 마감일·시험일·발표일 |
| **중복 묶기** | 여러 학과 게시판에 올라온 같은 공지를 하나로 묶고 "○○에도 올라왔어요" 표시 |
| **"나에게" 개인화** | 학과·관심사로 점수를 매기고 **추천 이유를 문장으로** 보여줌 — "내 학과(컴퓨터공학전공) 게시판에 올라온 공지예요" |
| **알림** | 웹 푸시(설치 없는 PWA) + 앱 안 알림함. 마감 7·3·1일 전, 접수 시작·마감 시각. 밤에는 모았다가 아침에 |
| **30초 설정** | 학과는 목록(70개)에서만 선택 — 줄임말(`컴공`)·초성(`ㄱㅎ` → 간호학과) 검색 |
| **편의 기능** | 별표 저장, 카카오톡 공유(링크를 열면 정리 카드로), 검색, 분야·마감임박 필터 |
| **관리자** | 수집 소스 켜기/끄기, 즉시 수집, 정답지 기반 분류 정확도 채점 |

## ⭐ 차별점

- **학과 게시판 109곳을 한 번에** — 학교 사이트가 같은 게시판 엔진을 쓴다는 점을 이용해 게시판 주소를 자동으로 찾습니다(`scripts/discover_boards.py`).
- **외부 AI 비용 0원, 데이터는 밖으로 안 나감** — 분류·추출이 모두 서버 안에서 돌아갑니다.
- **"왜 나에게?"를 설명하는 추천** — 블랙박스가 아니라 근거(내 학과 게시판, 관심 키워드)를 보여줍니다.
- **학교 공지 + 공모전·자격증·창업을 한 앱에서**
- **실제로 써 보며 다듬은 규칙**
  - 결과·수상자 발표는 관심사로 추천하지 않습니다(지원할 수 없는 글이 기회처럼 보이지 않게).
  - 본문에 한 번 스친 단어(채용공고 자격요건의 "AI 활용 능력")로는 추천하지 않습니다.
  - 신청기간과 운영기간을 구분하고, "신청 시작"을 마감으로 착각하지 않습니다.

## 📱 사용 흐름

```text
처음 접속 → 30초 설정(학과·관심사·알림) → [나에게] 탭: 추천 + 추천 이유
        → 공지 선택: 정리 카드(대상·기간·신청방법) → 별표 저장 / 공유 / 원문
        → 마감 7·3·1일 전 휴대폰 알림 → 알림함 · 캘린더에서 다시 확인
```

#### 알림 경로

알림은 휴대폰 웹 푸시와 앱 안 알림함 두 곳에 남습니다. 푸시를 허용하지 않은 사용자도 알림함에서 확인할 수 있습니다.

```powershell
cd backend
python scripts\gen_vapid.py   # VAPID 키쌍 생성 → .env에 붙여넣기
```

`VAPID_PUBLIC_KEY`와 `VAPID_PRIVATE_KEY`가 있으면 웹 푸시가 켜지고, 없으면 조용히 건너뜁니다.
웹 푸시는 **HTTPS에서만 동작**하며(localhost는 예외), **iOS는 홈 화면에 추가한 PWA에서만** 알림이 옵니다.

#### 학과·부속기관 공지사항 전체 수집

학교 사이트는 모두 같은 게시판 엔진(`/na/ntt/selectNttList.do`)을 쓰므로, 게시판 주소만 알면 같은 크롤러로 수집됩니다.
`scripts/discover_boards.py`가 단과대학 소개 페이지와 메인 페이지를 훑어 각 사이트의 '공지사항' 주소를 찾아
`app/crawlers/scnu_boards.json`에 저장하고, 앱은 시작할 때 이 목록을 수집 소스로 등록합니다(현재 109곳 + 기본 5곳(학사·장학·컴교·큐넷 API·직접 입력)).
학제 개편으로 생긴 "○○스쿨" 소개 페이지까지 따라가므로 전자·컴퓨터·인공지능공학전공 등 공대 학과 게시판도 포함됩니다.

```powershell
cd backend
python scripts\discover_boards.py        # 사이트 개편 시 다시 실행
python -m scripts.refetch_bodies         # 본문 추출 규칙을 바꾼 뒤, 저장된 공지 본문을 다시 받아 정리
```

- `robots.txt`는 `/upload/`, `/search/`만 막고 있어 공지 게시판 수집은 허용 범위입니다.
- 게시판 목록에서 **최근 `CRAWL_RECENT_DAYS`(기본 7)일 글만** 상세 페이지를 요청합니다. 게시판 사이에는 0.3초 간격을 둡니다.
- 본문은 문단(`p`, `div`, `li`, `tr`, `br`) 단위로만 줄을 나눕니다. `<span>`마다 끊으면 "접수기간 2026년 / 9 / 월"처럼 날짜가 흩어집니다.
- 학과 게시판 공지는 본문에 학과명이 없어도 출처로 판단해 해당 학과 학생에게 매칭됩니다. "전자공학과"와 "전자공학전공"처럼 끝말이 달라도 같은 학과로 봅니다.
- 게시일이 `NOTICE_RETENTION_DAYS`(기본 30)일을 넘긴 공지와 접수가 끝난 시험일정은 매 배치 끝에 목록에서 내립니다(삭제가 아니라 `archived` 상태, 알림 이력은 유지).
- 관리자 화면에 게시판마다 마지막 수집 시각·건수·오류가 표시되고, 오류 난 게시판이 맨 위로 올라옵니다.

#### 첨부파일 읽기

학교 공지는 본문에 "붙임 참조"만 쓰고 기간·대상을 첨부 한글 파일에만 적는 경우가 많습니다.
상세 페이지의 첨부(`/common/nttFileDownload.do`) 중 **HWP·HWPX·PDF·DOCX**를 공지당 최대 3개(각 5MB 이하)까지 받아
본문 뒤에 `[첨부파일: 이름]` 구간으로 붙입니다(`app/crawlers/attachments.py`). 이미지·스캔 PDF는 건너뜁니다.

- HWPX·DOCX는 zip 안의 XML을 문단 단위로, HWP는 OLE 본문 스트림의 문단 글자 레코드를, PDF는 pypdf로 읽습니다.
- 마감일은 **본문을 먼저** 보고, 본문에 없을 때만 첨부를 봅니다(첨부의 "서류 제출기한" 같은 부차적 날짜를 피하려고).
- 검색도 첨부 내용까지 찾습니다. 공지 목록 API는 원문(`raw_text`)을 응답에서 빼 가볍게 유지합니다.

#### 중복 공지 묶기

같은 공지가 학사공지와 학과 게시판에 함께 올라오면 제목을 비교해(말머리·기호 제거, 앞부분 일치, 유사도 0.93, 숫자가 다르면 별개)
하나로 묶습니다(`app/services/dedup.py`). 본부 게시판 글을 대표로 두고, 목록·알림에는 대표만, 카드에는 "외 N곳"으로 표시합니다.

#### 저장(별표)

- 카드·상세 창의 별을 누르면 저장되고, 매칭 여부와 상관없이 **마감 3일·1일 전과 당일에 알림**이 갑니다(마이페이지에서 목록 확인).
- 상세 창의 **캘린더에 마감 추가**는 `.ics` 한 건을 내려받습니다.

#### 화면 사용 흐름

- 메인 화면은 **상단 바 → 탭 → 검색 → 칩 → 목록** 다섯 층뿐입니다. 인사말·지표 타일·추천 카드 줄은 두지 않습니다.
  - 탭: **나에게**(학과·관심사 추천) / **학교** / **공모전·자격증**. 처음에는 추천이 있으면 "나에게"로 엽니다.
  - 칩: 전체 · **마감임박 N**(3일 안, `due=urgent`) · 분야들(자주 보는 순서) · 오른쪽 끝 정렬 전환(최신순/마감순). 스크롤해도 상단에 붙습니다.
  - 목록: 카드 대신 구분선으로 나눈 한 줄. 제목(최대 2줄), 분야·출처·날짜(한 줄), 오른쪽에 D-day와 별표. 기간·대상은 상세 창에서 봅니다.
  - 목록 끝 "더 보기"로 20건씩 이어 붙이고, 마감 지난 공지는 "마감 지난 공지도 보기"로 켭니다.
- 정렬의 마감순은 마감 전 공지만 가까운 순으로 보여줍니다(`sort=deadline`, `notices.deadline_date` 컬럼으로 DB에서 정렬).
- 알림·공유 링크는 `/?notice=<id>`로 앱 안 상세 창을 바로 엽니다. 앱이 이미 열려 있어도 알림을 누르면 그 공지로 이동합니다.
- 상세 창의 공유 버튼은 휴대폰 공유 시트(카카오톡 등)를 열고, 지원하지 않는 브라우저에서는 링크를 복사합니다.
- 처음 방문해 학과·관심사가 비어 있으면 **빠른 설정 창**(학과 목록·관심 칩·알림 켜기)이 한 번 뜨고, 저장하면 "나에게" 탭을 보여줍니다.
  닫아도 "나에게" 탭의 "30초 설정하기"로 다시 열 수 있습니다.
- "나에게 해당되는 공지"는 마감이 지난 공지를 빼고, 점수가 같으면 마감이 급한 것부터 보여줍니다.
- 상세 창에서 원문에서 못 찾은 칸은 "원문 확인: 신청방법 · 문의"처럼 한 줄로 모읍니다.
- 마이페이지의 학과는 실제 게시판 이름 목록(`/api/departments`)에서 고를 수 있고,
  관심 키워드는 자주 쓰는 말을 칩으로 눌러 넣습니다. 저장하지 않은 변경이 있으면 아래 저장 막대가 강조됩니다.
- 입력칸은 휴대폰에서 16px라 아이폰에서 눌러도 화면이 확대되지 않습니다.

#### 정확도 채점 (`/admin/eval`)

관리자 화면에서 공지마다 **정답 분류·마감일**을 확인해 저장하면("예측이 맞음" 한 번 또는 고쳐서 저장), 저장된 결과가 아니라
원문을 **지금의 분류기로 다시 돌려** 채점합니다. 분류 정확도, 마감일 정확도·정밀도(알린 마감 중 맞은 비율)·재현율(실제 마감 중 찾은 비율),
분류별 정확도, 틀린 사례를 보여줍니다.

```powershell
python -m scripts.evaluate          # 규칙만
```

#### 마감일과 매칭 규칙

- 마감일은 "까지·마감·신청기간" 같은 단서 주변, 또는 "신청·접수·제출" 라벨 바로 뒤 날짜에서만 뽑습니다. "일시·장소·발표·시상" 라벨이 붙은 날짜는 행사 날이므로 마감으로 쓰지 않습니다.
- 관심 키워드의 영문 약어는 단어 경계를 지킵니다(`AI`가 `Gmail` 안에서 잡히지 않음). `AI↔인공지능`, `취업↔채용·인턴`처럼 자주 쓰는 동의어를 함께 봅니다(`INTEREST_SYNONYMS`).
- 카테고리 확정 키워드는 제목을 먼저 봅니다. 본문에 "학자금"이 지나가듯 나오는 "추가등록 안내"는 장학이 아니라 학사입니다.

#### 데이터 출처 원칙

수집 대상은 **순천대 게시판**, **공식 발급 API(공공데이터포털 등)**, **관리자가 직접 적은 일정** 세 가지뿐입니다.
다른 기관·민간 사이트(시험 접수 사이트, 공모전 모음 사이트)는 허락 없이 수집하지 않습니다.
크롤러는 요청 전후로 주소를 검사해(`app/crawlers/base.py`의 `ensure_school_url`) `scnu.ac.kr`와 그 하위 도메인이 아니면
요청하지 않고, 학교 주소로 요청했더라도 다른 사이트로 넘겨지면 그 내용을 버립니다. 첨부파일과 관리용 스크립트도 같은 검사를 거칩니다.

#### 자격증 시험 일정

크롤링 대신 [공공데이터포털 국가자격 시험일정 API](https://www.data.go.kr/data/15074408/openapi.do)를 사용합니다.
활용신청 후 받은 인증키를 `DATA_GO_KR_KEY`에 넣으면 수집되고, 키가 없으면 해당 소스만 조용히 건너뜁니다.

시험 일정도 **별도 모델 없이 공지 하나로 저장**합니다. 접수 마감일이 `deadline`이 되므로
D-day 표시·개인화 매칭·마감 리마인더가 학교 공지와 똑같이 동작합니다.

공식 API가 없는 시험(토익·텝스·오픽·한국사 등)은 시행기관 공지를 보고 `app/crawlers/manual_exams.json`에 회차를 적습니다
(형식은 `app/crawlers/manual.py` 설명 참고). 날짜에 `HH:MM`을 붙이면 접수 시작·마감 시각 알림까지 걸립니다.

#### 알림 규칙 (`app/services/delivery.py`, `app/services/alarms.py`)

| 알림 | 언제 | 대상 |
|---|---|---|
| 새 공지 | 매시간 수집 직후. 한 사람에게 4건 이상이면 **알림 하나로 묶음**("새 공지 23건 · 경진대회 12 · 자격증 8") | 나에게 해당되는 공지 |
| 마감 7·3·1일 전 | 그날 **오전 9시 이후** 첫 수집. 여러 건이면 "마감 임박 N건"으로 묶음 | 받은 공지 + 별표 저장 |
| 접수 시작 1시간·5분 전·시작 | 1분마다 확인해 정시에 | 시작 시각이 적힌 일정(직접 입력한 시험 등) |
| 접수 마감 1시간·10분 전·마감 | 1분마다 확인해 정시에 | 마감 시각이 공개된 일정 |

- 사용자가 마이페이지에서 **새 공지 / 마감 알림 / 접수 시각 / 밤에는 조용히**를 각각 끄고 켤 수 있습니다(`user_profiles.alert_prefs`).
  꺼도 휴대폰으로만 안 울릴 뿐, 알림함에는 그대로 쌓입니다.
- **방해 금지** `QUIET_HOURS_START`~`QUIET_HOURS_END`(기본 23~8시, 한국 시간): 새 공지 알림을 보내지 않고 모았다가 끝난 뒤 묶어서 보냅니다.
  시각 알림은 사용자가 받기로 한 일정의 정해진 시각이라 방해 금지와 상관없이 보냅니다.
- 날짜만 알려진 마감(학교 공지·큐넷 등)은 시각을 추측하지 않고 날짜 알림만 겁니다.
- 서버가 잠깐 멈췄다 돌아오면 10분 안의 알림은 늦게라도 보내되, 같은 시작·마감에 대해서는 가장 최근 것 하나만 보냅니다
  (이미 시작한 뒤 "5분 전"을 보내지 않음). 보낸 알림은 `alarm_logs`에 남겨 두 번 보내지 않습니다.
- 공지 상세 창에 이 공지로 울릴 "알림 예정" 시각이 표시됩니다.
- 시각 알림 시점은 `.env`의 `ALARM_OPEN_MINUTES`(기본 `60,5,0`)·`ALARM_CLOSE_MINUTES`(기본 `60,10,0`)로 바꿀 수 있습니다.
  2026-09-25에 `10,5,1`로 실제 휴대폰 발송을 시험해 21:03·21:08·21:12(예정 시각 +10초)에 나간 것을 확인했습니다.
- 1분마다 도는 시각 알림은 `notices.open_at/close_at` 인덱스로 "곧 시작·마감하는 공지"만 골라 그 알림 대상만 읽고,
  날짜 알림은 `deadline_date`가 7·3·1일 뒤인 공지만 읽습니다.

#### 성능 측정 (`python -m scripts.benchmark [학생 수] [공지 수]`)

실제 DB를 건드리지 않고 메모리 DB에 운영 규모 데이터를 만들어 무거운 작업을 잽니다. 학생 2,000명·공지 3,000건(받은 공지 6만 건) 기준:

| 작업 | 최적화 전 | 최적화 후 |
|---|---|---|
| 1분마다 시각 알림 확인 | 3,098ms | 97ms |
| 중복 묶기(매시간 2번) | 11,776ms | 802ms |
| 아침 날짜 알림(하루 1번) | 6,116ms | 2,698ms |

서버를 시작할 때 모델에 선언된 인덱스 중 기존 DB에 없는 것을 자동으로 만듭니다(`app/database.py`).

#### 알림함 (`/alerts`)

앱에 들어와서 알림을 직접 확인하는 화면입니다. 상단 종 아이콘에 안 읽은 수가 배지로 붙습니다.

- **받은 알림**: 새 공지·마감 7·3·1일 전·접수 시작/마감 시각 알림이 모두 쌓입니다(`inbox_items`). 날짜별로 묶고,
  안 읽은 것은 강조합니다. 누르면 읽음 처리되고 공지 상세로 이동합니다. "모두 읽음" 지원.
- **예정된 알림**: 앞으로 2주 안에 울릴 알림을 시각 순으로 보여줍니다(`GET /api/inbox/upcoming`).
- **푸시를 못 받아도 쌓입니다.** 아이폰에서 홈 화면에 추가하지 않았거나 알림을 거부한 사람도 같은 알림을 여기서 봅니다.
  새 공지는 매칭되는 즉시 기록되므로, 방해 금지 시간이라 푸시가 아침으로 미뤄져도 앱에서는 바로 보입니다.
- 휴대폰 알림이 꺼져 있으면 알림함 위에 "켜기" 안내가 뜹니다. 지원하는 기기에서는 푸시가 오면 앱 아이콘에 표시가 붙고, 알림함을 열면 지웁니다.
- API: `GET /api/inbox`, `GET /api/inbox/unread-count`, `POST /api/inbox/read`(ids 없으면 전부), `GET /api/inbox/upcoming`.

#### 목록 출처 탭

학교 공지 / 공모전·자격증 / 전체 탭으로 나눕니다(`/api/notices?origin=school|external`). 기본은 학교 공지이고,
공모전·자격증 탭은 게시일이 없어 마감 임박순으로 엽니다. 최신순에서는 마감 지난 공지를 기본으로 숨깁니다(`hide_closed=true`).
보던 탭·분야·정렬은 탭을 닫기 전까지 기억합니다(세션 저장소).

#### 캘린더 화면 (`/calendar`)

월간 달력에 공지 **마감(빨강)·시험일(파랑)·발표일(초록)**을 점으로 표시하고, 날짜를 누르면 그날 일정을 나열합니다(누르면 상세 창).
"전체"와 "내 공지·저장"(나에게 해당되는 공지 + 별표 저장)을 바꿔 볼 수 있고, 지난 달도 볼 수 있게 목록에서 내려간 공지도 포함합니다.
시험일·발표일은 본문의 `시험일: …`, `성적발표: …`, `합격자발표: …` 줄에서 뽑아 `structured_json.schedule`에 두며,
API: `GET /api/calendar/events?start&end&scope=all|mine`.

#### 카테고리 분류 방식

`학사·장학·취업·행사·기타`는 임베딩 유사도로 판정하고, 유사도가 임계값(0.32)에 못 미치면 `기타`로 둡니다.
`연구실·안전`은 범위가 좁아 임베딩만으로는 오탐이 잦아(모집·점검 성격 공지를 모두 끌어당김)
`학부연구생`, `안전교육` 같은 확정 키워드로만 도달하게 했습니다. 확정 키워드는 언제나 임베딩보다 우선합니다.

### 배포 (현재 운영 구성)

- **API·수집·알림**: Oracle Cloud ARM 서버. 저장소 루트에서 `sudo bash deploy/oracle-sslip/install.sh` 한 번으로 Python 가상환경, Node, systemd 서비스(`scnu-lens-api`, `scnu-lens-web`), Caddy https까지 설치합니다. 다시 실행하면 코드만 갱신하고 `.env`·DB는 그대로 둡니다. 자세한 내용은 `deploy/oracle-sslip/README.md`.
- **화면**: Vercel(`frontend/`). `vercel.json`이 `/api/*` 요청을 Oracle 서버로 넘기므로 브라우저 입장에서는 같은 주소라 CORS 설정이 필요 없습니다.

### 운영 주의

- 학교 사이트(`scnu.ac.kr`) 외 주소는 수집하지 않도록 코드에서 막고 있습니다. 요청 빈도는 매시간·최근 7일치로 제한합니다.
- 게시판 구조가 바뀌면 `scripts/discover_boards.py`로 주소를 다시 찾고, 상세 파서는 `app/crawlers/scnu.py`에서 고칩니다.
- 분류·마감일은 참고용입니다. 화면에서 항상 원문 링크로 재확인하도록 안내합니다.
- `ADMIN_API_KEY`, VAPID 비밀키, 공공데이터 키는 저장소에 올리지 않습니다(서버 `.env`, 권한 0600).
