# SCNU Lens — 순천대 공지·공모전·자격증 알리미 (간단한 웹앱 버전)

순천대학교 여러 게시판의 공지와 공모전·자격증 일정을 한곳에 모아 보고,
내 학과·관심 키워드에 맞는 공지를 골라 주는 웹앱입니다. 서버 없이 파일 두 개로 동작합니다.

- `index.html`: 화면·디자인·기능 전체
- `notices.js`: 공지 데이터(개인정보 없음)

`index.html`을 더블클릭하면 PC에서 바로 열립니다.

## 기능
- **탭**: 나에게 / 학교 / 공모전·자격증
- **검색**: 제목·게시판·내용
- **빠른 필터**: 마감임박(3일 안), 분야별(학사·장학·취업·행사·경진대회·자격증 등), 최신순 ↔ 마감순
- **D-day**: 한국 날짜 기준, 3일 이하는 빨간색
- **나에게**: 학과와 관심 키워드를 고르면 맞는 공지만 추천하고 이유를 보여줌
  - 예: "내 학과 게시판", "관심: 공모전, AI"
  - "AI"를 고르면 "인공지능"·"머신러닝" 공지도 찾음
- **상세 창**: 대상·기간·신청방법·문의 등 정리된 정보, 원문 보기, 캘린더에 추가(.ics, 하루 전 알림 포함)
- **저장**: 별표로 저장, 내 설정에서 모아 보기
- **캘린더**: 월 달력에 마감일(빨간 점)과 접수 시작·시험·발표일(파란 점), 날짜를 누르면 그날 일정
- **기타**: 라이트/다크 모드, 휴대폰·PC 반응형

학과·관심 키워드·저장 목록은 이 기기 브라우저에만 저장되고, 서버로 보내지 않습니다.

## 데이터 출처
- 순천대학교 공식 게시판(학사·장학·학과·부속기관 공지)
- 공공데이터포털 공식 API
  - 한국산업인력공단 국가자격 시험일정
  - 한국데이터산업진흥원 데이터 자격검정(ADsP·SQLD 등)
  - 창업진흥원 K-Startup

자동으로 정리한 내용이라 틀릴 수 있으니, 신청 전에는 원문을 꼭 확인하세요.

## 전체 버전과의 차이
이 폴더는 서버 없이 도는 간단한 버전입니다. 전체 버전(같은 저장소의 `backend/`, `frontend/`)은 다음 기능을 더 갖고 있습니다.
- 순천대 게시판 109곳을 매시간 자동 수집
- AI 임베딩 모델로 분류
- 마감 7·3·1일 전과 접수 시작·마감 시각에 휴대폰 웹 푸시 알림

데이터를 새로 뽑으려면 전체 버전에서 다음을 실행합니다.

```bash
cd backend
python -m scripts.export_static
```
